# Security

The Security team focuses on protocol security, smart contract auditing, agent safety analysis, and infrastructure hardening. The team works across all Flow Research products and protocols to identify and mitigate risks.

## Getting Started

- [OWASP Smart Contract Security Verification Standard](https://scs.owasp.org/SCSVS/) — by **OWASP**. Controls for smart contract architecture, code, governance, access control, and related risks.
- [Smart Contract Security](https://swcregistry.io/) — by **SWC Registry**. Common smart contract vulnerabilities and test cases.
- [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/) — by **OWASP**. Common security risks for LLM-based applications.
