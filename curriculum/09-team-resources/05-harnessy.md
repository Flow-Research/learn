# Harnessy

Harnessy is the reliability layer for Flow Research's agent ecosystem. It tests agent behavior, evaluates task output quality, and closes the feedback loop so agents can be trusted with real work.

## Getting Started

- [A Practical Guide for Evaluating LLMs and LLM-Reliant Systems](https://arxiv.org/abs/2506.13023) — by **Ethan M. Rudd et al.** Framework for evaluating real-world LLM systems.
- [Evaluation and Benchmarking of LLM Agents: A Survey](https://arxiv.org/abs/2507.21504) — by **Mahmoud Mohammadi et al.** Survey of agent evaluation objectives, processes, and benchmarks.
