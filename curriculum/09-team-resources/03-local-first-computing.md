# Local-First Computing

Local-first computing prioritizes offline-capable, user-owned data and peer-to-peer synchronization over centralized cloud dependency. The team explores CRDTs, sync protocols, edge storage, and resilient application architectures.

## Getting Started

- [Local-First Software](https://www.inkandswitch.com/local-first/) — by **Ink & Switch**. The seminal essay defining local-first principles.
- [Automerge Documentation](https://automerge.org/docs/hello/) — an accessible introduction to CRDT-backed local-first application state.
- [A Conflict-Free Replicated JSON Datatype](https://arxiv.org/abs/1608.03960) — by **Martin Kleppmann and Alastair R. Beresford**. The paper behind Automerge.
